# orchestra-mcp/pack-mobile

React Native mobile development skills and agents

## Install

```bash
orchestra pack install github.com/orchestra-mcp/pack-mobile
```

Or via MCP:
```
install_pack(repo: "github.com/orchestra-mcp/pack-mobile")
```

| Agents | mobile-dev |
| Hooks | None |
